오픈소스 고지

최종 업데이트: 2026-06-18

한자쏘옥은 앱 기능 구현을 위해 일부 공개 데이터와 오픈소스 자료를 사용합니다. 아래 고지는 해당 자료의 출처와 라이선스 조건을 명확히 하기 위한 것입니다.

  • 라이선스 URL: https://creativecommons.org/licenses/by-sa/3.0/
  • 라이선스 전문: assets/data/licenses/CC-BY-SA-3.0.txt, docs/legal/licenses/CC-BY-SA-3.0.txt
  • 사용 범위: 일부 한자 획순/획 중심선 SVG path 데이터를 앱의 JSON seed 형식으로 변환해 사용합니다.
  • 변경 사항: 앱 내 콘텐츠 식별자에 맞춰 선별, 정렬, JSON 구조 변환, 일부 글자 매핑 및 검수 메타데이터를 추가했습니다.

  • 라이선스: Arphic Public License 1999
  • 라이선스 전문: assets/data/licenses/ARPHICPL.TXT, docs/legal/licenses/ARPHICPL.TXT
  • 사용 범위: 일부 한자의 stroke median 데이터를 앱의 109x109 좌표계 SVG path seed로 변환해 사용합니다.
  • 변경 사항: 일부 글자를 선별하고, median point를 앱 좌표계의 SVG path seed로 변환했으며, 앱 콘텐츠 식별자와 검수 메타데이터를 추가했습니다.

자체 제작 데이터

수동 캡처 또는 한자쏘옥 제작 워크플로에서 생성한 획 데이터는 앱 내부 제작 데이터로 관리합니다. 해당 항목은 seed 메타데이터의 source와 licenseNote에 별도로 표시됩니다.
